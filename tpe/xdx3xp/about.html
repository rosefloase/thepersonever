about xDx3xP

hello! i'm jade, the person behind this... music project
most of my music takes inspiration both from the music that i enjoy now, and the songs i listened to when i was younger. did i say songs? i meant nintendo DS soundtracks and flipnote audio

some time in 2022, i started making music due to just. being bored! i used LMMS at first, due to not being able to fully install windows programs at the time (we love you portableapps <3)
when i started out, i was really into pokemon mystery dungeon... specifically, explorers of darkness. so, i looked up a soundfont for the explorers games, and used that as my primary soundbank! however, as i became more familiar with my music software, i began to want more unique sounds... so, i started using more and more soundfonts!!
eventually, thanks to my EPIC FRIEND AUTUMN SKATEBOARD (aka scalarknight), i found out about fl studio! and vsts! and easy-to-use instrument and effect plugins!!! one trip to the internet archive later, i had a copy of fl studio 20 :D
i used that for a while, but i had to use the 32-bit version due to 20's built-in soundfont player only being supported on the 32-bit executable. finding out (with the help of scalarknight) that the 32-bit version just had horrible export times, i moved over to fl studio 21, due to it having a 64 bit version of the soundfont player!!!!
for a while i ran fl studio 21 under manjaro, using bottles. bottles worked okay enough for fl studio, but i couldn't get it to work for flash... thus, i moved back to windows 10
when i switched back to windows 10, i upgraded to fl studio 24! it worked pretty good... my only note is that '24 has a cool new boot-up screen similar to other art programs i've used :D
recently, i've switched to linux (this time using mainline arch) and i got '24 up and running pretty easily. i had to configure wine myself this time, but honestly? i much prefer not having to rely on bottles for every single goddamn program i have to use. while it's been pretty good to me so far, i've had a few issues with some niche vsts not updating their ui, some performance loss, and (albeit only recently) some context menus hiding behind other ui elements. the benefits (not using windows) mostly outweigh the cost for me though, so i've only been *sorta* looking out for a linux-native daw that i can use like i use fl studio

go back?
